# Web Studio Landing Page

A static landing page for a web design and development studio.

## Project Overview

This project contains a single-page responsive website built with HTML and CSS.

Key elements:
- Hero section with a call-to-action button
- Navigation header with contact links
- Feature cards showing studio advantages
- Team section with staff profiles and social links
- Custom styles using Google Fonts and normalized browser defaults

## Files

- `index.html` — main page markup
- `css/styles.css` — layout and styling
- `images/` — graphics and icons used on the page
- `prettierc.json` — formatting configuration

## Run Locally

1. Open `index.html` in your browser.
2. Alternatively, launch a simple static server from the project folder if preferred.

### Recommended local preview using Node.js

```bash
# from project root
npx serve .
```

Then open the displayed local URL in your browser.

## Notes

- The site uses `modern-normalize` for consistent browser rendering.
- The design is ready for further extension into a full multi-page portfolio.
